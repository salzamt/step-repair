# Contributing

## Before opening a pull request

- Keep each change focused and explain the CAD or repair scenario it addresses.
- Do not commit STEP, STL, or other CAD assets by default. If a fixture is
  essential, discuss its size and redistribution rights first.
- Preserve the tool's validation and STEP round-trip checks unless the change
  explicitly replaces them with equivalent safeguards.
- Run the checks documented in the README and, when possible, test with a
  representative model through FreeCAD.

## Pull requests

Describe the input geometry, expected output, FreeCAD version, and the commands
used to verify the change. Do not include proprietary or confidential models in
issues or pull requests.
